# majadigi-superapp
mono-repositori untuk majadigi-superapp, mencakup infrastruktur, service, dan mobile.

## Cara Menjalankan Backend
```
cd infrastructure
docker compose up --build
```


## Menjalankan Mobile App
```
cd mobile/majadigi-app
flutter pub get
flutter run
```
